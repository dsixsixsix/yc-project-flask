# Структура проекта

```
YC Project/
├── app/                      # Основной пакет приложения
│   ├── __init__.py          # Инициализация Flask приложения
│   ├── config.py            # Конфигурация
│   ├── models/               # Модели базы данных
│   │   ├── __init__.py
│   │   ├── role.py          # Модель роли
│   │   ├── user.py          # Модель пользователя
│   │   └── item.py          # Модель элемента
│   ├── routes/               # Маршруты (контроллеры)
│   │   ├── __init__.py
│   │   ├── auth_routes.py   # Аутентификация (регистрация, логин)
│   │   ├── iam_routes.py    # IAM сервис
│   │   ├── items_routes.py  # CRUD операции с элементами
│   │   └── main_routes.py   # Главная страница
│   ├── services/             # Бизнес-логика
│   │   ├── __init__.py
│   │   ├── auth.py          # Сервис аутентификации
│   │   └── storage.py       # Сервис работы с Object Storage
│   ├── utils/                # Утилиты
│   │   ├── __init__.py
│   │   ├── decorators.py    # Декораторы для проверки прав
│   │   └── error_handlers.py # Обработчики ошибок
│   └── templates/            # HTML шаблоны
│       └── index.html       # Главная страница
├── terraform/                # Terraform спецификация
│   ├── main.tf
│   ├── variables.tf
│   ├── outputs.tf
│   └── terraform.tfvars.example
├── app.py                    # Точка входа приложения
├── requirements.txt          # Зависимости Python
├── Dockerfile               # Docker образ приложения
├── docker-compose.yml       # Docker Compose конфигурация
├── nginx.conf               # Конфигурация Nginx
└── README.md                # Документация
```

## Описание модулей

### `app/models/` - Модели данных
- `role.py` - Роли пользователей (admin, user, guest)
- `user.py` - Пользователи системы
- `item.py` - Элементы для CRUD операций

### `app/routes/` - Маршруты (контроллеры)
- `auth_routes.py` - Регистрация и аутентификация
- `iam_routes.py` - IAM сервис (проверка токенов, создание тестовых пользователей)
- `items_routes.py` - CRUD операции с элементами
- `main_routes.py` - Главная страница с веб-интерфейсом

### `app/services/` - Бизнес-логика
- `auth.py` - Генерация/проверка JWT токенов, получение текущего пользователя
- `storage.py` - Работа с MinIO/S3 (загрузка, удаление файлов)

### `app/utils/` - Утилиты
- `decorators.py` - Декоратор `@require_role()` для проверки прав доступа
- `error_handlers.py` - Глобальные обработчики ошибок

### `app/templates/` - HTML шаблоны
- `index.html` - Главная страница с веб-интерфейсом

## Преимущества такой структуры

1. **Разделение ответственности** - каждый модуль отвечает за свою область
2. **Легкость поддержки** - легко найти нужный код
3. **Масштабируемость** - легко добавлять новые функции
4. **Тестируемость** - каждый модуль можно тестировать отдельно
5. **Читаемость** - понятная структура для новых разработчиков
